# Plantilla de publicación LinkedIn (Alset / PrismaTec)

Usar cuando se pida: *“genera la publicación de LinkedIn”* o *“artículo para reclutadores”*.

## Estructura obligatoria

1. **Gancho** (1–2 líneas): qué construiste, en qué lenguaje, qué problema toca.
2. **Qué resuelve** (viñetas): 5–8 capacidades concretas, sin jerga vacía.
3. **Cómo está hecho** (2–4 líneas): modularidad, tests, CI, docs, deploy.
4. **Por qué lo compartes** (2–3 líneas): interés profesional, no marketing vacío.
5. **CTA suave**: conectar / revisar repo.
6. **Enlaces**: repo, guía, relay, landing.
7. **Hashtags**: 5–8 técnicos (#Golang #DistributedSystems …).

## Tono

- Profesional, claro, en **español** (salvo que pidan inglés).
- Orientado a reclutadores y perfiles técnicos: impacto + stack + rigor.
- Sin afirmar que es blockchain, LLM de producción o reemplazo de sistemas enterprise.
- Sin inventar métricas (usuarios, stars) si no están verificadas.

## Datos a refrescar antes de generar

- Últimos hitos del README / commits / PRs mergeadas
- URL relay y landing
- Si hay CI, docs nuevas, evaluar-zyrion, API v2, etc.

## Salida

Dos versiones:
- **Completa** (post largo o artículo)
- **Corta** (≈500–900 caracteres)
