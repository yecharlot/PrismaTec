## Texto para pegar

Construí **Alset (P.TEC-AN v4.0)** — una red peer-to-peer en **Go** donde cada proceso es un nodo capaz de coordinar datos, lógica y automatización en el borde.

No es un tutorial suelto: es un sistema desplegable, documentado y con CI.

**Qué resuelve**
• Nodos **libp2p** (local o relay en la nube) con el mismo binario  
• **Agentes** con identidad, saldo de aplicación y contenido anclado por CID  
• Apps publicables en la malla (`/w/nombre.app.ans`)  
• **Lisp embebido (LispAI)** para automatizar el nodo por HTTP  
• **Zyrion**: lógica ternaria (0 / 1 / 2) y un DSL de decisión (`evaluar-zyrion`) para políticas y flujos multi-estado  
• Modelos ligeros (embedding, capas, inferencia) guardados como agentes  
• Auth (tokens/roles), módulos y **API v2** para integraciones  
• Persistencia en disco o **Supabase**  
• **CI en GitHub Actions** (vet, test, build) en cada PR  

**Cómo está hecho**
Arquitectura modular (`cmd/` + `internal/`), tests, guía de uso, documentación de API y landing pública. Relay en producción para probar la API sin instalar nada.

**Por qué lo comparto**
Me interesa el diseño de sistemas distribuidos reales: red, automatización, reglas explícitas y operación (CI, deploy, docs), no solo demos aisladas.

Si trabajas en backend, sistemas distribuidos, plataforma o edge computing, me encantará conectar.
