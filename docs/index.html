P.TEC-AN v4.0 · código abierto

Red peer-to-peer programable en el borde

Nodos libp2p con agentes, apps por CID, intérprete Lisp, lógica ternaria Zyrion, modelos ligeros, tokens y API v2. El mismo binario sirve en local o como relay.

Repositorio Relay en vivo Guía completa
git clone https://github.com/yecharlot/PrismaTec.git && cd PrismaTec && go run ./cmd/prisma-tec

Dos modos, un binario

El comportamiento lo decide la variable de entorno RENDER.

Local Nodo completo

  • API HTTP y panel de administración
  • Cliente y servidor de pulsos SSE
  • Malla libp2p + persistencia disco/Supabase
  • LispAI, Zyrion y modelos

Relay Punto de sincronización

  • Servidor de pulsos (sin cliente, evita bucles)
  • Misma API pública
  • Ideal en Render u otros hosts
  • Enlace de nodos detrás de NAT

Capacidades

Todo opera dentro del mismo nodo.

🔗

Red libp2p

DHT, GossipSub, streams y bloques por CID entre peers.

👤

Agentes

Identidad, saldo UTXO, RootCID y nombres *.app.ans.

📦

Apps en la malla

Registro multipart y apertura en /w/nombre.app.ans.

λ

LispAI

Intérprete embebido por POST /api/lispai para automatizar el nodo.

⬡

Zyrion 0·1·2

Lógica ternaria y evaluar-zyrion con :entradas / :salidas.

◈

Modelos ligeros

Embedding, capas, inferencia y entrenamiento exploratorio en agentes.

🔑

Auth y módulos

Tokens, roles, módulos y entidades para organizar permisos y piezas.

🛠

API v2

Crear agentes, transferir saldo, publicar e instalar apps de forma explícita.

🗄️

Persistencia

Disco local o Supabase; CIDs en blockstore del nodo.

LispAI y Zyrion

Decisiones y automatización sin recompilar el nodo.

Ejemplo en vivo

Estado 0 → BLOQUEO cuando las entradas son bajas:

(evaluar-zyrion (quote (N :entradas (X Y) :salidas ((0 BLOQUEO) (1 OK) (2 RARO)))) (quote (X 0.1 Y 0.1)))

Agentes, DNS, CID, embedding, crear-capa-lineal, inferir, entrenar-hebbiano, host-id, net-peers, transferencias vía API v2.

Empezar en 3 pasos

1. Clonar y arrancar

go run ./cmd/prisma-tec — API en el puerto 8080.

2. Probar Lisp

POST /api/lispai con {"cmd":"(+ 1 2)"} o un evaluar-zyrion.

3. Publicar una app

POST /api/apps/register y abrir /w/nombre.app.ans.

Para qué sirve (y para qué no)

Sí

Mallas P2P propias, apps ancladas a CID, automatización con Lisp, políticas ternarias, prototipos de contrato lógico, demos de IA en el borde, relays públicos.

No (aún)

Sustituir blockchains públicas, custodia legal de valor entre desconocidos, ni un LLM de producción.
