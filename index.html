P.TEC-AN v4.0 · código abierto

Red peer-to-peer lista para nodos reales

Alset convierte cualquier máquina en un nodo de la red: habla con otros peers, guarda estado, evalúa Lisp y participa en una capa ligera de IA distribuida.

Repositorio Nodo relay en vivo
git clone https://github.com/yecharlot/PrismaTec.git && cd PrismaTec && go run ./cmd/prisma-tec

Una sola base de código, dos modos

El mismo binario sirve en un portátil o en la nube. El comportamiento lo decide una variable de entorno.

Local Nodo completo

Sin RENDER

  • API HTTP y panel de administración
  • Cliente de pulsos SSE
  • Conexión a la malla libp2p
  • Persistencia en disco o Supabase

Relay Punto de sincronización

Con RENDER definida

  • Servidor de pulsos SSE
  • API y sincronización de estado
  • Sin cliente de pulsos (evita bucles)
  • Ideal en Render u otros hosts

Qué incluye

Piezas pensadas para operar juntas, no como demos aislados.

🔗

Red libp2p

DHT, GossipSub y streams entre pares. Identificadores de contenido estilo IPFS sin depender de un daemon aparte.

λ

Motor Lisp

Intérprete embebido para scripts y automatización. Habla con el nodo a través de una interfaz clara, no de globals sueltos.

⚡

Pulsos SSE

Eventos en tiempo real entre nodos locales y relays. Útil cuando la malla P2P no alcanza o hay NAT de por medio.

🧠

IA distribuida

Estado neuronal, sinapsis y memoria ligera que puede propagarse entre nodos. Orientada a experimentación, no a modelos gigantes.

📦

Agentes y bloques

Registro de agentes, CIDs y nombres DNS internos. API HTTP para crear, listar y sincronizar estado.

🗄️

Persistencia

Disco local por defecto. Supabase opcional con tablas separadas para agentes, bloques y estado neural.

Stack

Tecnologías que verás en el código y en el despliegue.

Go 1.26 libp2p GossipSub CID / multihash Lisp embebido SSE Supabase Render Docker
